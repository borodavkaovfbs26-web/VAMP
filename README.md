# VAMP

Статичний сайт онлайн-школи для GitHub Pages із Supabase.

## Файли
- `index.html` — головна сторінка
- `login.html` — вхід і реєстрація
- `script.js` — основна логіка кабінету (підключається сторінками)
- `supabase.js` — клієнт Supabase
- `style.css` — спільні стилі
- `supabase-schema.sql` — схема таблиць і політики доступу

` scriptt.js ` залишено як резервний файл; HTML-сторінки його не підключають.

## Публікація
Завантаж файли репозиторію в GitHub і дочекайся оновлення GitHub Pages.

## Supabase
Перевір структуру наявних таблиць перед запуском SQL. Не запускай SQL поверх таблиць із відмінними колонками без резервної копії.
Публічний publishable/anon ключ можна використовувати у браузері; `service_role` ключ ніколи не додавай у файли сайту.
