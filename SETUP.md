# VAMP — налаштування

Для покрокового запуску з уже створеною базою Supabase дивись **START-HERE-UK.md**.

Код Edge Function для безпечного створення користувачів: `supabase/functions/create-user/index.ts`.

**Безпека:** `SUPABASE_SERVICE_ROLE_KEY` зберігається тільки в Supabase Edge Function Secrets. Ніколи не вставляй його у фронтенд або GitHub.

**Відео:** поточна WebRTC-кімната — прототип 1:1 із STUN. Для стабільної роботи потрібен TURN; для групових уроків, запису та демонстрації екрана потрібен окремий медіасервер/SFU.
